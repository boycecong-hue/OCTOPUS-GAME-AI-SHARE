# 首页封面改版设计说明

日期：2026-03-26
范围：AI Coding 技术分享会首页（封面页）

## 1. 背景

当前首页能够完整表达分享主题，但整体视觉更接近常规公司分享封面，缺少与“AI Coding / Agent / CLI / 新研发范式”主题匹配的未来感与舞台冲击力。

本次改版目标不是调整整套内容结构，而是在保持现有 Markdown 驱动演示架构不变的前提下，显著提升封面页的第一眼气质，使其更像一场关于 AI 驱动研发范式演进的未来发布会开场。

## 2. 目标

本次首页改版需要达成以下目标：

1. 视觉上明显摆脱“普通企业 PPT 首页”的观感。
2. 首页气质与主题高度一致，能够传递 AI、智能体、未来研发系统的感觉。
3. 保持标题与主题信息清晰，不因追求视觉冲击而牺牲可读性。
4. 保持当前站点结构稳定，不引入新的构建流程、框架或复杂运行依赖。

## 3. 风格方向

已确认的首页风格方向为：**未来科技感**。

具体表达上采用“**AI 发布会主视觉 + 智能体系统感**”的混合方案：

- 外层体验是发布会级别的 Hero 封面，强调第一屏的视觉冲击力。
- 内层语言借助智能体网络、数据流、控制界面等抽象元素，让页面与 AI Coding / Agent / CLI 主题建立明确关联。
- 整体气质应偏高级、冷峻、克制，不走夸张赛博朋克，也不回退到纯黑客终端风。

## 4. 信息层级设计

首页信息优先级按以下顺序排列：

1. **主题气质**：先让观众感受到“这是一个关于未来研发方式的分享”。
2. **主标题**：明确活动事件名与核心命题。
3. **副标题 / 标语**：用一句更有势能的话强化分享主张。
4. **辅助信息**：讲者、时间、重点议题。

该层级意味着首页不再像传统目录页或会务信息页，而是先承担“开场建立场域”的职责。

## 5. 版式方案

首页采用四段式结构：

### 5.1 顶部轻量品牌信息

保留现有组织标识信息：

- `OCTOPUS GAME / GALAXY STUDIO / TECH SHARE`

但将其作为低权重的信息带存在，作用是提供场景归属，而不是成为视觉焦点。

### 5.2 中央 Hero 主视觉区

首页中心区域承担核心视觉任务，包含两层标题：

- 英文事件名：`AI Coding 2026`
- 中文主标题：`开发范式演进：从辅助到自主`

设计上要求：

- `AI Coding 2026` 更像事件名、代号或发布会标题。
- 中文主标题更像核心宣言，承担主题表达。
- 两者共同构成首页的视觉中心。

### 5.3 一句强概念副标语

副标语需要从“说明文”升级为“开场宣言”。

保留现有表达意图，但语气更锋利、更适合作为未来科技风首页文案。推荐从以下两类中选择其一落地：

- 宣言型：强调 AI 从辅助走向自主，软件研发进入下一个范式。
- 舞台型：强调观众正在进入智能体驱动的软件工程时代。

实现阶段不要求逐字使用当前候选句，但必须遵守这两个要求：

1. 语气要有势能，不写成普通说明句。
2. 必须与“Agent 驱动研发范式”主题直接相关。

### 5.4 底部系统信息带

将当前 `Speaker / Timeline / Agenda` 的普通信息块改为更像未来控制界面的“系统参数带”或“Mission Brief”。

建议结构为三组信息：

- `Speaker`
- `Session` 或 `Event Time`
- `Focus`

其中 `Focus` 用于替代传统列表式 Agenda。表达形式不再使用普通 Markdown 列表，而采用标签、短条目或系统字段样式，例如：

- Concepts
- CLI Suite
- SDLC Workflow

## 6. 视觉语言

### 6.1 整体基调

采用深色背景与冷色科技氛围，关键词如下：

- 深空
- 智能体网络
- 数据流
- 控制界面
- 冷光

### 6.2 配色原则

建议使用如下配色关系：

- 主背景：深蓝黑 / 深空蓝
- 主强调色：电光蓝、蓝紫、青色辉光
- 辅助色：冷白、灰蓝

视觉原则为：**大面积克制，关键位置发光**。

### 6.3 背景表达

背景不依赖外部图片素材，优先通过 CSS 构建抽象科技背景，以保持项目轻量和可控。背景元素可包含：

- 微弱网格或坐标场
- 模糊光晕
- 极细流线
- 节点或连线暗示
- 柔和渐变层次

这些元素的职责是暗示“Agent network / context flow / command routing”，而不是变成具象插画。

### 6.4 标题表现

标题需要成为视觉信号中心，强调方式包括：

- 更大的字号层级
- 更强的字重对比
- 局部渐变高亮或辉光
- 更精细的字距与行距控制

要求最终效果更接近未来发布会主视觉，而非普通网页标题块。

### 6.5 信息组件风格

讲者、时间、重点议题等辅助信息组件建议采用：

- 半透明面板
- 低对比边框
- 微弱辉光
- 标签化字段结构

避免传统表格式或普通卡片式演示信息块。

### 6.6 动态策略

允许加入轻量动态效果以增强“活着”的感觉，但不引入复杂动画系统。可接受的动态范围包括：

- 渐入
- 轻微漂移
- 背景辉光缓慢变化
- hover 微交互

动态应服务于氛围，而不是喧宾夺主。

## 7. 内容保留与调整

### 保留内容

以下内容仍应保留在首页中：

- `AI Coding 2026`
- `开发范式演进：从辅助到自主`
- 讲者信息
- 时间信息
- 核心议题概览

### 调整内容

以下内容需要调整表达方式：

- 当前副标题：从说明句升级为更有势能的标语。
- 当前 Agenda：从 Markdown 列表改为低密度的 focus 标签或参数项。
- 当前装饰线条：删除或替换为更贴近科技感的视觉元素。

### 删除或弱化内容

以下表达不建议继续保留原样：

- 过于模板化的几何小装饰线
- 传统二栏底部信息块的普通会务感
- 首页出现过强的目录页感

## 8. 实施范围

本轮实现限定在最小有效范围：

### 主要修改

- `sections/00-cover.md`

主要用于重写首页的内容结构与语义块组织。

### 可能修改

- `index.html`

仅用于增加少量支撑首页气质的通用样式类，例如：

- Hero 容器
- glow / grid / panel / tag 等视觉类
- 首页深色视觉所需的基础样式

### 明确不做

本轮不包含以下内容：

- 全站主题重做
- 其他章节视觉改版
- 引入前端框架或构建系统
- 大规模响应式重构
- Canvas / WebGL / 重型动画效果

## 9. 成功标准

改版完成后，首页应满足以下标准：

1. 第一眼明显比当前版本更未来、更高级、更符合 AI Coding 主题。
2. 页面视觉与“Agent / CLI / 新研发范式”主题一致。
3. 信息仍清晰可读，不因视觉强化而降低演讲表达效率。
4. 与现有 Markdown 驱动结构兼容，不增加额外维护负担。

## 10. 实施建议

建议按以下原则实施：

- 保持当前首页核心主题不变，只升级视觉表达与信息层次。
- 将首页从“静态封面说明”升级为“未来发布会 Hero 场景”。
- 样式支撑尽量放入 `index.html` 的可复用类中，避免把大量视觉细节继续堆在 `00-cover.md` 的 inline style 里。
- 首页的最终观感应接近“进入一个 AI 驱动研发时代的开场界面”，而不是一张普通 PPT 首页。
